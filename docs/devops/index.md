# DevOps & CI/CD

DevOps handlar om att korta vägen från kod till produktion. CI/CD (Continuous Integration / Continuous Deployment) automatiserar bygg, test och driftsättning så att varje commit kan nå produktion med minimal mänsklig handpåläggning.

## I det här kapitlet

- GitHub Actions — bygga pipelines i yaml
- Azure Pipelines — CI/CD i Azure DevOps
- Bicep — infrastruktur som kod
- Miljöer och hemligheter i pipelines
