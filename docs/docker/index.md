# Docker

Containers är grunden för modern molndrift. Docker låter dig paketera en applikation med allt den behöver — runtime, bibliotek, konfiguration — i en portabel enhet som körs likadant oavsett miljö.

## I det här kapitlet

- Vad är en container och varför?
- Images och Dockerfile
- docker-compose för lokala miljöer
- Publicera till Azure Container Registry (ACR)
- Köra containers i Azure Container Instances (ACI)
