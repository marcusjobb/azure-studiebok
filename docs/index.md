# Azure studiebok

{: .important }
**Det här är inte en kurs.** Det är ett uppslagsverk. Du förväntas inte läsa det från början till slut — du använder det när du glömt hur man kopplar en Managed Identity, när du undrar vad skillnaden är mellan ACI och AKS, eller när du ska sätta upp en pipeline och inte minns exakt syntaxen.

Hitta det du söker, förstå det, gå tillbaka till portalen.

---

Boken används i kursen **Administrera molnlösningar** på ITHS och uppdateras löpande i takt med undervisningen.

## Innehåll

- **Docker** — containers, images, Dockerfile, docker-compose
- **Azure** — App Service, Storage, Entra ID, Key Vault, VNet, CosmosDB
- **DevOps** — CI/CD med GitHub Actions och Azure Pipelines
- **Kubernetes** — grunderna, AKS, deployments och services
- **Ordlista** — termer och begrepp inom moln och DevOps
- **Resurser** — videomaterial (KakashiDota) och Microsoft Learn per vecka
