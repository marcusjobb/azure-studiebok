# Kubernetes

Kubernetes (K8s) är ett system för att köra och skala containeriserade applikationer. Azure erbjuder det som en managad tjänst — Azure Kubernetes Service (AKS).

## I det här kapitlet

- Grundbegrepp: Pod, Node, Cluster, Namespace
- Deployments och ReplicaSets
- Services och ingress
- AKS — Kubernetes i Azure
- Helm för pakethantering
