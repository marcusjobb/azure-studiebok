# Ordlista

Termer och begrepp inom moln, containers och DevOps.

| Term | Förklaring |
|------|-----------|
| **ACI** | Azure Container Instances — köra en container utan att hantera servrar |
| **ACR** | Azure Container Registry — privat register för Docker-images |
| **AKS** | Azure Kubernetes Service — managad Kubernetes i Azure |
| **Bicep** | DSL för att definiera Azure-infrastruktur som kod |
| **CI/CD** | Continuous Integration / Continuous Deployment |
| **Container** | En isolerad körmiljö med allt en applikation behöver |
| **Dockerfile** | Recept för att bygga en Docker-image |
| **Entra ID** | Azures identitets- och åtkomsttjänst (fd. Azure Active Directory) |
| **Image** | En infryst mall för en container |
| **Key Vault** | Azure-tjänst för att lagra hemligheter, nycklar och certifikat |
| **K8s** | Förkortning för Kubernetes (8 bokstäver mellan K och s) |
| **Pod** | Minsta körbara enhet i Kubernetes — en eller flera containers |
| **Registry** | Lager för container-images (Docker Hub, ACR) |
| **VNet** | Virtual Network — privat nätverk i Azure |
